# Changelog

All notable project changes are recorded here. This prototype follows semantic versioning for repository releases; third-party source data keeps its own publisher version and terms.

## [0.2.0] — 2026-08-13

### Changed

- Split Replay frontend orchestration into focused UI state, source workspace, map interaction and view modules without changing its operator contract.
- Added focused replay transition tests and retained the verified desktop/phone behavior.
- Consolidated the root README into a concise product entry point with five current public-demo screenshots.
- Added canonical architecture, product-design and documentation-index sources of truth.
- Documented Situation-first review, typed evidence, Field Tasks, Decisions, versioned COP and the Mock WCC Ticket boundary in ADR 0005.
- Reconciled the 33-source registry, source research inventory and reproducible sample/full-data build instructions.

### Safety boundary

- No new external WCC connection, dispatch, warning publication or model authority was added.
- Mock and Simulation remain evidence weight `0` and excluded from training, calibration and accuracy claims.

## [0.1.0] — 2026-08-13

- First supported public prototype release with security policy and headers, scoped mutation CORS, Ruff, reproducible sample data and refactored CSS/ontology foundations.
